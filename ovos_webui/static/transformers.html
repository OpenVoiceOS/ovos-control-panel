Transformers

Dashboard

Transformers are small plugins that change a request as it moves through the device. Each stage below is its own chain. Turn a plugin on or off, set the order the device runs them in, and edit a plugin's own settings. Every change is saved to the configuration file.

These settings change how the device understands and answers you, so this page needs an access token, like the other device pages.

Bidirectional translation

Talk to the device in another language and hear the answer back in the same language. This turns on two translation plugins together: one translates your words into the device's own language, the other translates the reply back.

The ovos-bidirectional-translation-plugin is not installed. Install it on the Plugins page first.

These are the same as the extra languages on the Voice settings page.

Voice tuning

Change how the spoken voice sounds by applying sound effects to it: pitch, speed, reverb and tone. This uses the SoX speech transformer.

The ovos-tts-transformer-sox-plugin is not installed. Install it on the Plugins page first.
